# Код пайплайна

Здесь выборочно выложены файлы рабочего пайплайна, чтобы числа в документах были проверяемы.
Данные соревнования не приложены (они принадлежат организаторам), поэтому «как есть» код не
запустится без `train.parquet`, `valid.parquet` и стартерпака с `utils.py`.

| файл | что делает |
|---|---|
| `train.py` | обучение: признаки, `StatefulGRU`, три режима лосса (взвешенный MSE, блочный взвешенный Пирсон, дистилляция), веса строк по маске, сегментное обучение с переносом состояния |
| `eval.py` | оценка официальным скорером на срезах (tail120 / slice) |
| `pack_zip.py` | сборка сабмита: ONNX-графы + рантайм, проверка контракта и размера |
| `feat_eng.py` | инженерия признаков (та часть, что закрыта отрицательными результатами) |
| `run_fg_cell.sh` | образец канонического пуска (hid 96, 2 слоя, 5 эпох, corr-mix 0.5, маска) |

Ключевые куски, на которые ссылаются документы:

- `block_wp_torch` в `train.py` — блочный взвешенный Пирсон, повторяющий официальную метрику;
- `StatefulGRU` — `nn.GRU(112 → hid, 2 слоя)` с вынесенным состоянием для ONNX;
- веса строк: `--row-weight-col is_scored` и гибридный сплит 10 607;
- дистилляция: `--kd-ckpts` / `--kd-alpha` (MSE к предсказаниям учителя).
