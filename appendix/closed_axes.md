# Закрытые оси проекта (перенос из внутренней базы знаний)

Это исходный реестр закрытых направлений: 86 записей в семи разделах, каждая с числом и
конвенцией измерения. Публикуется как есть, с оговоркой: часть записей закрыта по критерию
«соло-счёт ниже текущей записи», и именно этот критерий разобран в `docs/07_lessons.md`
как главная методологическая ошибка кампании.

# 60 — CLOSED: закрытые оси

«Закрыто» = есть число, которое опровергает гипотезу, либо арифметика, которая
делает её невыполнимой. Переоткрывать можно только с новым механизмом и новым
пререгом; повтор того же дизайна — потеря GPU-часов.
